<h2><a href="https://www.geeksforgeeks.org/problems/common-divisors4712/1">Common Divisors</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given two positive integers <strong>a</strong> and <strong>b</strong>, return the count of all positive integers that are divisors of both a and b.</span><br><br><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input</strong>: a = 12, b = 24
<strong>Output:</strong>&nbsp;6&nbsp;

</pre>
