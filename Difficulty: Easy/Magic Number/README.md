<h2><a href="https://www.geeksforgeeks.org/problems/magic-number4431/1">Magic Number</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given an integer <strong>n</strong>, find the nth <strong>magic</strong> number. </span><span style="font-size: 18.6667px;">A magic number is a positive integer that can be represented as the sum of distinct powers of 5. In other words, every power of 5 can be used at most once in the representation.</span></p>
<p><span style="font-size: 18.6667px;">For example:</span></p>
<ul>
<li><span style="font-size: 18.6667px;">5 = 5<sup>1</sup></span></li>
<li><span style="font-size: 18.6667px;">25 = 5<sup>2</sup></span></li>
<li><span style="font-size: 18.6667px;">30 = 5<sup>1</sup> + 5<sup>2</sup></span></li>
</ul>
<p><span style="font-size: 18.6667px;">When all magic numbers are arranged in <strong>increasing</strong> order, return the nth magic number.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 1
<strong>Output:</strong> 5
<strong>Explanation</strong>: The magic numbers in increasing order begin as: 5, 25, 30, 125, ...
The 1st magic number is 5.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: n = 2
<strong>Output:</strong> 25
<strong>Explanation</strong>: The magic numbers in increasing order begin as: 5, 25, 30, 125, ...
The 2nd magic number is 25.</span></pre>
